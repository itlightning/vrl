Improve VRL compile time for programs with deep `else if` chains (`O(n^2)` to `O(n)` complexity over number of arms). Additionally remove redundant type-state clones in binary operator type checking, add identity short-circuits to type-state merges, and skip no-op state merges for coalesce operations with side-effect-free fallbacks (a further ~5x compile-time improvement measured on large real-world programs).
